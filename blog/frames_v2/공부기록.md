# 액자 v2 공부기록 (디자인실+알팀 액자반, 26-11-26)

## 1. 왜 v1이 "그림판·엑셀 느낌"이었나 (원인)
- v1은 CSS `border: 14px solid #1C1C1C` + inset 그림자. 실제 액자를 진짜로 보이게 하는 신호 4개가 전부 없었음:
  1) **재질 신호 없음** — 단색 면. 실제 나무·포일은 결이 미세하게 흐름.
  2) **조각 신호 없음** — 실제 액자는 네 조각을 45도로 잘라 붙임 → 모서리 대각 이음선, 위·아래 가로결/좌·우 세로결.
  3) **단면 신호 없음** — 앞면 바깥 모서리는 빛을 받고 안쪽 경사는 어둠. 변마다 빛 받는 정도가 다름(위·왼 밝고 아래·오른 어둠).
  4) **두께 신호 약함** — 벽 그림자가 대칭에 가까움(빛 방향 불명).
- 이번 v2는 네 신호를 모두 넣고, 재질은 '사진 질감'만 씀(그라데이션 재질 흉내 0).

## 5. '디지털 목업이 진짜처럼 보이는 요소' 정리 (웹 공부 + 실물 대조에서 추린 것)
1. 결 방향이 변을 따라감 + 45도 이음선 (가장 큰 신호)
2. 조각마다 색·결이 조금씩 다름 (같은 무늬 반복 = 가짜 신호)
3. 단면 빛: 바깥 둥근모 밝음 / 안쪽 경사 어둠, 변마다 반대
4. 이너프레임 단 사이의 어두운 틈 + 앞면이 안쪽으로 드리우는 그림자(빛 쪽 변만 진하게)
5. 벽 그림자는 빛 반대쪽으로 비대칭, 가까운 진한 그림자 + 먼 옅은 그림자 2겹
6. 유리 반사 번쩍임은 오히려 싸구려 목업 신호 → 넣지 않음(대표님 철칙과도 일치)
- 유튜브·핀터레스트: 이 세션 컨테이너·원격 브라우저에서 youtube.com·pinterest.com 접근이 프록시로 막혀 직접 보지 못함 → 위 6개는 웹 문서·실물 사진 대조로만 도출. **다음 회차 보완 과제**(대표님 맥 크롬 세션에서).
